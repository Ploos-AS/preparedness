# Preparedness book template

A book repository derived from this template uses one shared project with two editorial editions.

```text
book.yaml
no/
  00-frontmatter.md
  01-introduction.md
en/
  00-frontmatter.md
  01-introduction.md
assets/
data/
references/
```

## Rules

1. Chapter numbering should remain aligned where practical.
2. NO is Norway-first; EN is Europe-first.
3. Localisation may change examples, authorities and regulatory sections.
4. Facts with safety, legal or regulatory impact require sources and review dates.
5. All four production outputs are first-class: HTML, EPUB, Kindle and PDF.
6. Production logic belongs in Ploos-AS/publishing; book repositories contain content and metadata.
