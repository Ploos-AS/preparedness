# M3 — First toolkit implementation

M3 turns the toolkit contract into working Go software.

## Delivered

- `cmd/ploos-prep` offline CLI.
- Reusable `internal/calc` calculation core.
- `water`, `battery` and `power` commands.
- Human-readable and versioned JSON output.
- Unit tests.
- Contract tests consuming the M2 YAML vectors.
- CI build/test qualification.
- CLI documentation with explicit assumptions.

## Boundary

M3 deliberately does not add a GUI. The calculation core is kept UI-independent so a later desktop or PWA interface can reuse it without changing the formulas.
