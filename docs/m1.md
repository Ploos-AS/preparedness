# M1 — Validation and book contract

M1 turns the M0 conventions into machine-checkable contracts.

## Acceptance criteria

- JSON Schema for book manifests.
- JSON Schema for country data.
- Repository validator.
- GitHub Actions validation on pushes and pull requests.
- NO/EN book skeleton.
- HTML, EPUB, Kindle and PDF remain mandatory first-class outputs.
- Publishing implementation remains delegated to `Ploos-AS/publishing`.
- Country facts can carry verification state, source metadata and review dates.

## Next

M2 will establish the reusable toolkit/data API, stronger NO/EN parity checks, source freshness checks and a book-bootstrap workflow.
