# Når strømmen går / When the Power Goes Out

First Ploos Beredskap / Ploos Preparedness book project.

The book is a concise, practical guide to household power cuts. The Norwegian edition is Norway-first; the English edition is written for a European audience rather than adapted from US preparedness assumptions.

## Editorial promise

The reader should finish with a tested household power-cut plan, not merely a shopping list.

The book covers immediate actions, heat, light, food and water, backup power, information/communications and practical worksheets. Technical calculations should integrate with `ploos-prep` where useful.

## Production

First-class outputs: HTML, EPUB, Kindle and PDF through Ploos publishing infrastructure.

This directory is the canonical M4 bootstrap source and is intended to become its own book repository.
