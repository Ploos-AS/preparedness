# Reservestrøm

Reservestrøm begynner med behov, ikke produkt. Lag tre lister: **må fungere**, **bør fungere** og **komfort**. Registrer watt, timer per døgn og eventuelle startbehov.

Små laster som telefon, lys og radio kan ofte dekkes effektivt med USB-batteribanker. Større 230 V-laster krever raskt langt mer energi. Bruk `ploos-prep battery` og `ploos-prep power` for å gjøre antakelsene synlige.
