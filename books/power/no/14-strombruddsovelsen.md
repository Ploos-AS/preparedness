# Strømbruddsøvelsen

Test planen mens strømmen fortsatt virker. La være å bruke ordinære løsninger i en avtalt periode uten å koble ut sikkerhetskritisk utstyr.

Prøv lys, ett beredskapsmåltid, telefonlading, radio/informasjon, varmeplan og arbeidsark. Noter hva som manglet, hva som var upraktisk og hvilke antakelser som var feil. Øvelsen er ferdig først når planen er oppdatert.
