# Norway — source register

Publication-sensitive Norwegian claims must be checked against authoritative sources and carry a review date.

Initial authoritative source set:

- DSB — Egenberedskap / one-week preparedness guidance.
- DSB — Slik beholder du varme og lys hvis strømmen går.
- DSB — Trygg bruk av gassovner.
- DSB — Slik unngår du kullosforgiftning.
- DSB — Bruk og oppbevaring av små gassbeholdere.
- DSB — Mat du bør ha i hus i tilfelle krise.

The source register is intentionally separate from prose so claims can be re-reviewed before each edition.
