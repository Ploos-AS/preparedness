# M2 — Toolkit and reusable data contracts

M2 establishes the boundary between books, shared preparedness data and software.

## Acceptance criteria

- Stable v1 machine-readable toolkit result schema.
- Offline-first toolkit architecture documented.
- Initial deterministic test vectors for water and battery/power calculations.
- NO/EN chapter parity manifest.
- Validator checks chapter-pair existence.
- Validator rejects impossible provenance states such as `verified` without verification metadata.
- Book bootstrap contract documented.
- No duplication of publishing implementation.

M2 intentionally defines calculation contracts before building a polished GUI.
